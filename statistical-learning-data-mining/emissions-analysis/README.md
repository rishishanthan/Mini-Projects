# 📱 Device Usage Classification  

This project focuses on building **classification models** using a device usage dataset to predict outcomes from behavioral and demographic features.  

---

## 📂 Contents
- `data/used_device_data.csv` – dataset on device usage.  
- `emissions analysis.Rmd` – R Markdown file with full analysis.  
- `emissions analysis.html` – rendered HTML report.  

---

## 🔍 Analysis Overview
- Performed exploratory analysis and preprocessing of the device dataset.  
- Implemented supervised learning methods:  
  - Logistic Regression  
  - Decision Trees  
  - Random Forests  
- Evaluated models using train/test splits and cross-validation.  
- Compared performance with accuracy, precision, recall, and confusion matrices.  

---

## 📊 Key Results
- **Random Forest** achieved the highest predictive performance.  
- Logistic Regression provided a solid baseline.  
- Decision Trees allowed interpretability but had higher variance.
