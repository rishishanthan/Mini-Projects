# 📊 Statistical Learning & Data Mining

These projects demonstrate applications of **supervised and unsupervised learning, clustering, and time series modeling** using **R**.  

This collection highlights my ability to work with **real datasets**, apply a variety of **statistical learning techniques**, and evaluate models for interpretability and predictive performance.  

---

## 📌 Clustering (USArrests Dataset)
- Applied **K-Means clustering** with multiple initializations (`nstart=1 vs 20`).  
- Compared **hierarchical clustering methods**: complete, average, single linkage.  
- Assessed the effect of **feature scaling** on clustering.  
- Clustered US states based on crime statistics.  

**Skills:** clustering, scaling, dendrograms, unsupervised learning  

---

## 📌 Advanced Time Series
- Worked with multiple datasets (`larain`, `color`, `oilfilters`, `tempdub`, `rwalk`).  
- Applied **trend regression, seasonal decomposition, harmonic regression**.  
- Performed **residual diagnostics** (ACF, QQ plot, Shapiro test, runs test).  
- Simulated random processes (Normal, Chi-square, t-distribution).  

**Skills:** regression with seasonality, diagnostic testing, random process simulation  

---

## 📌 ARIMA & Seasonal Models
- Simulated **AR, MA, and ARMA processes** and visualized autocorrelation structures.  
- Modeled **oil price** and **electricity consumption** series, applying **Box-Cox transformations**.  
- Analyzed **seasonal wage and beer sales** using regression with seasonal indicators.  

**Skills:** ARIMA modeling, Box-Cox transformation, seasonal regression  

---

## 📌 Forecasting with ARIMA
- Fitted **harmonic regression** and ARIMA models on `tempdub` dataset.  
- Forecasted with **AR(1), MA(2), ARMA(1,1)** processes.  
- Modeled **CO₂ concentration time series** with seasonal ARIMA.  
- Compared forecast performance and residual behavior across models.  

**Skills:** ARIMA forecasting, residual analysis, seasonal modeling
