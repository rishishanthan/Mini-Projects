Probability Theory

This repository contains small projects and code of probability theory with applications in data science and statistics in R Markdown and its knited pdf.

---

## 📘Overview

- Probability concepts and axioms  
- Discrete and continuous random variables  
- Probability distributions (Binomial, Poisson, Normal, etc.)  
- Joint distributions and conditional probability  
- Random sampling and parameter estimation  
- Derived distributions and transforms  
- Elementary stochastic processes (Bernoulli, Poisson)  

---

## 📂 Repository Contents

### **Project 1**
- Files:  
  - `Project1.Rmd` (R Markdown source)  
  - `Project1.pdf` (rendered report)  
- Focus: Application of probability distributions, estimation, and simulations using R.  
- Tools: R, RMarkdown, statistical analysis libraries.  

### **Project 2**
- Files:  
  - `Project2.Rmd` (R Markdown source)  
  - `Project2.pdf` (rendered report)  
- Focus: Advanced probability analysis, random sampling, Monte Carlo simulations, and parameter estimation.  
- Tools: R, RMarkdown, Monte Carlo methods, data visualization.  

---

## 🚀 How to Run

1. Install **R** and **RStudio** (or any R environment).  
2. Open the `.Rmd` files in RStudio.  
3. Knit to PDF or HTML to reproduce the reports.
